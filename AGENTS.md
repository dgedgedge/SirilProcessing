# Instructions pour les agents

Avant toute intervention dans ce dépôt, lire et appliquer les consignes communes
contenues dans [.github/copilot-instructions.md](.github/copilot-instructions.md).
Lire et appliquer également [.copilot/config.json](.copilot/config.json),
notamment les sections `default`, la section du langage concerné et `testing`.
Le JSON est une source de consignes complémentaire, à lire explicitement ;
ne pas supposer que l’outil utilisé le charge automatiquement.

`.github/copilot-instructions.md` reste la référence commune détaillée : y
maintenir les règles de travail plutôt que les dupliquer ici. En cas de
contradiction entre les deux sources, ses consignes priment sur le JSON.

Appliquer notamment ses exigences de qualité Python et de docstrings, de mise
à jour des guides des scripts et des pages spécialisées sur les modules et
algorithmes, et de vérification de toute nouvelle fonctionnalité documentée.
Ces exigences font partie des critères de réalisation de chaque modification.

Pour les modifications de documentation, lire également
[docs/CONTRIBUTING.md](docs/CONTRIBUTING.md).

Ces consignes concernent tout le dépôt ; les instructions explicites de
l'utilisateur et les règles de l'environnement restent prioritaires.
