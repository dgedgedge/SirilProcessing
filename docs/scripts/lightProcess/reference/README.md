# lightProcess — références de données

[Documentation](../../../README.md) › [lightProcess](../README.md)

Les [séquences Siril](SIRIL_SEQUENCE.md) représentent les images, leurs mesures,
leur inclusion et les transformations d’alignement. Cette référence décrit
la lecture, la modification et l’écriture utilisées par les traitements.

Les responsabilités générales du module restent présentées dans
[le catalogue des bibliothèques](../../../architecture/LIBRARIES.md).

La [factory de sessions et l’API sirilpy](SIRIL_API.md) décrit le lancement
automatique, les appels, les objets reçus, les journaux et les dépendances.
